# PasswordSecurity

## How to run

Make sure you have Java installed on your computer.

### 1. Compile
Open terminal in this folder and compile the file:
```bash
javac -encoding UTF-8 PasswordSecurity.java
```

### 2. Run
Then run it with:
```bash
java PasswordSecurity
```

*(Note: To test Part 5 dictionary attack, put `Rockyou.txt` in the same folder).*
